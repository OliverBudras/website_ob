# Oliver Budras — Academic Website

A responsive, static academic homepage built from the supplied CV, with a clean editorial style inspired by the reference Google Sites page. It does not include a “Things I like” section.

## Preview locally
Open `index.html` in a browser. No build step or dependencies are required.

## Publish with GitHub Pages
1. Create a GitHub repository named `YOUR-USERNAME.github.io` (or any repository if you plan to use project pages).
2. Upload `index.html` and `styles.css` to the repository root.
3. In repository Settings → Pages, select deployment from the `main` branch and `/ (root)`.
4. Visit the URL GitHub Pages provides.

## Before publishing
- Review the wording of the biography and research descriptions.
- Confirm the current institutional affiliations and contact emails.
- Optionally add a professional photograph, Google Scholar/ORCID/RePEc links, downloadable CV, and a News section.

The site intentionally avoids inventing profile links, news items, or claims not present in the CV.
